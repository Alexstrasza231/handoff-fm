# 用量速查（HandoffFM v0.1.2）

首页能看到三件事：两位刚做了什么、**当前任务**已记录多少 Tokens，以及去哪里看细节。
点 **查看详情 → 过程记录 / 用量明细**，可按 Codex 或 DeepSeek 筛选；详情还能切换"会话累计"。
**输入含缓存、输出含推理**，缓存和推理都只是子集，不会额外加进总量。
默认统计最近一次 Codex 用户指令及明确关联的 DeepSeek 任务，未关联的调用不计入当前任务。
Tokens 只是**已记录的消耗**，不是费用、账单、账户额度或余额。
任务**经过时间**包含等待与工具执行，不能当成模型思考时间。
字段缺失会显示 **未提供 / 尚未采集**；**部分数据** 表示只知道部分已记录消耗。
晚启动采集不会补造之前的数字，旧记录没有真实采样就仍显示未采集。
DeepSeek 与 Codex 的数据都来自本地日志/流，只保留可信来源的计数。
想了解口径细节，请看 `docs/usage-tokens.zh-CN.md`。
